# Герой WOS для Codex

1. Прочитай [общую процедуру TEST → MAIN](../../../.claude/skills/wos-new-hero/SKILL.md)
   и [точки интеграции](../../../.claude/rules/heroes.md). Читай эталон по символам,
   а не целиком; проверь актуальность его API в системах.
2. Определи реальный выбранный файл героя и активный TEST-профиль по
   [test_map/README](../../../test_map/README.md). Не переноси старую MAIN-копию
   вместо импортированного TEST-кода. Категорию/сложность возьми из запроса;
   rawcode сверяй по текущим объектам, не угадывай.
3. Используй предусмотренный dry-run для переноса и проверь предлагаемые изменения.
   Уже разрешённое создание/перенос выполняй в этом объёме без повторного согласования;
   это не разрешение на отдельный запуск игры. Объекты/ассеты и ручные CastCheck/tooltip
   подключения проверяй отдельно: Hero Transfer не выполняет всю интеграцию.
4. Для проверки/записи используй `wos-sync` и
   [VALIDATION](../../../docs/ai/VALIDATION.md); не заявляй готовность TEST по MAIN compile.
5. Зафиксируй долговечный контракт/нетривиальный сбой в существующих документах по
   AGENTS.md. Ссылку общего Skill на Auto Memory трактуй как проектную файловую
   память Codex. Кратко укажи проверки и оставшуюся игровую проверку.
