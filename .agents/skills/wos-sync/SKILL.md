# Синхронизация WOS для Codex

1. Прочитай [общую процедуру](../../../.claude/skills/wos-sync/SKILL.md).
   Это существующий процесс проекта; не создавай вторую копию его команд.
2. Выбери направление и MAIN/TEST из запроса. Для побочных эффектов проверки,
   разделения компиляции MAIN/TEST и сборки прочитай соответствующий раздел
   [VALIDATION](../../../docs/ai/VALIDATION.md). Не запускай export без необходимости.
   При восстановлении MAIN прочитай CP59 в `docs/ai/KNOWLEDGE.md`: рабочий
   исполняемый скрипт может быть новее WCT. Import/build parity не обходить.
3. Выполни запрошенные шаги из корня; ошибки/конфликты check останавливают запись.
   Требование закрыть World Editor без сохранения перед записью остаётся обязательным.
4. Уже данная пользователем авторизация на save/сборку достаточна; не запрашивай её
   повторно из-за формулировки общего Skill. Запуск игры определяется запросом.
   Git Bash команды адаптируй к текущей оболочке, сохрани код выхода и смысл флагов.
5. Сообщи выполненные шаги, результат и существенные ограничения кратко.
   Долговечные знания обнови в существующей проектной документации по AGENTS.md;
   Auto Memory Claude не использовать как механизм памяти Codex.
