# Инструменты компиляции WOS

В `JassHelper/` находится полный набор файлов используемого компилятора:

- `jasshelper.exe` — компиляция vJASS в JASS.
- `pjass.exe` — проверка полученного JASS.
- `jasshelper.conf` — настройка вызова pjass из JassHelper.
- `sfmpq.dll` — чтение и сборка архивов карт MPQ; библиотека 32-битная.
- Лицензии и описание pjass сохранены рядом с программами.

Конфигурация `.vscode/wos-build.json` и её пример используют путь
`utility\JassHelper\jasshelper.exe` относительно папки проекта.
Исходные инструменты в каталоге Warcraft III сохранены.
Контрольные суммы поставленных файлов находятся в `compiler-manifest.json`.
Временные логи и резервные копии компилятора не входят в поставку.

Остальные части сборки уже находятся в проекте:

- `libs/common.j`, `libs/Blizzard.j` — используемые стандартные библиотеки.
- `.vscode/compile-vjass.ps1`, `.vscode/build-run-w3-map.ps1` — сценарии компиляции и сборки.
- `.vscode/test-map-archive.ps1` — работа с архивом карты через `sfmpq.dll`.
- `tools/` — вспомогательные сценарии подготовки и проверки проекта.

Для сценариев нужны установленный Python 3 и Windows PowerShell.
Они являются системными средами выполнения, а не файлами компилятора.

Проверка компиляции из корня проекта: `python tools/check_wos_ui.py`.
