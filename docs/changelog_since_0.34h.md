- Развеивание (Kairoseki Cuffs и др.) корректно снимает положительные баффы. Очищение снимает больше дебаффов: Hell Blaze, Sukuna's Curse, Five Elements Seal, Kairoseki, Frostnova F, стихийные метки и др.

- Возврат полной цены за предмет: 15 → **20 с** (и для Quick Buy / Auto Buy). Минус в Quick Buy убирает рецепт целиком.
- Обновлены рекомендованные сборки всех героев.
- AUTO SELECT HERO — по желанию (по умолчанию выкл.) и держит камеру на герое.
- Фикс: смена высоты полёта у способностей больше не сбрасывает прицел.
- HUD: «+N» золота за следующий раунд считается правильно.
- F2: ники крупнее, колонка MVP шире; старая панель статов ALT убрана.
- Окно стихий показывает реальные значения урона и длительностей.
- Длинные значения КД на кнопках (например «3/6») больше не обрезаются.
- UI-текстуры переведены в BLP (меньше вес карты).
