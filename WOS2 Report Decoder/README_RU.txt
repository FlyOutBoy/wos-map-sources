WOS2 REPORT DECODER — ТОЛЬКО ДЛЯ АДМИНИСТРАТОРА

ВАЖНО
В папке находится серверный декодер с секретом. Не публикуйте, не отправляйте
игрокам и не кладите эту папку в общий Google Drive.

ИСПОЛЬЗОВАНИЕ
1. Найдите оригинальный WOS2_bot_match_*.txt, созданный Warcraft III.
2. Перетащите TXT мышью на файл «Decode WOS2 Report.bat».
3. ACCEPTED означает, что сервер примет контейнер и его подпись. Рядом появится
   проверенный файл *_decoded.txt.
4. Если подпись неверна, программа всё равно расшифрует доступное содержимое в
   *_decoded_UNVERIFIED.txt. Этот файл предназначен только для диагностики:
   сервер исходный контейнер отклонит.
5. В окне также выводится расшифрованный текст отчёта.

Для старого отчёта без WOS2E-заголовка декодер возьмёт match ID из стандартного
имени WOS2_bot_match_<ID>.txt и выполнит диагностическую расшифровку.

ТРЕБОВАНИЕ
Нужен установленный Node.js LTS. Проверить можно командой: node --version

Не редактируйте исходный отчёт перед проверкой: изменение даже одного символа
должно нарушать контрольную подпись.
